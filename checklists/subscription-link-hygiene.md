# 订阅链接保管与泄露处理

订阅链接**不需要密码**——谁拿到这串网址，谁就能用你的套餐。所以它的安全等级应当和账号密码一样。

## 常见的泄露途径与对策

| 途径 | 怎么发生 | 怎么避免 |
| --- | --- | --- |
| 直接分享 | 发给朋友、同学、群里“一起用” | 不分享；多设备用你自己的设备数额度 |
| 截图 | 把客户端界面或设置页截图发出去 | 发图前遮住链接和令牌 |
| 在线订阅转换 | 把链接粘贴到第三方转换网站 | 优先用服务商提供的对应格式 |
| 公开仓库 / 笔记 | 把配置文件推到公开仓库、贴到公开笔记 | 配置里的订阅链接用占位符，或放私有仓库 |
| 聊天记录 / 云笔记 | 书签、聊天历史里留存 | 用密码管理器保存，定期清理 |
| 求助时全文贴出 | 在论坛、群里提问时贴出完整链接 | 求助时把令牌部分换成 `xxxx` |

## 日常习惯

- [ ] 用密码管理器保存订阅链接，不放在聊天软件的“收藏”里
- [ ] 每台设备用客户端的“导入”功能，不要反复复制粘贴到各种地方
- [ ] 分享前先问自己：对方需要吗？有没有更安全的替代方式？
- [ ] 定期查看设备数与流量使用情况，异常增长要警觉

## 一旦泄露，按顺序处理

1. **立即重置订阅链接**：登录服务商后台，找到“重置订阅”或“更换订阅地址”，旧链接随之失效；
2. **检查设备与流量**：看是否有陌生设备在线、流量是否异常消耗，记录下来；
3. **在所有自己的设备上换成新链接**，确认能连接；
4. **回顾泄露途径**：是分享、截图还是转换服务？找出原因，避免再次发生；
5. 被封禁或流量被盗用时，带上记录联系客服。
