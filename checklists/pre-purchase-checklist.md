# 买前检查清单

付款前逐项过一遍。**红旗不等于“一定有问题”，而是“值得多核实一步”**；信号越多，越要控制投入。

## 价格

- [ ] 我把价格统一成了“第一个月要付多少”和“折算每月多少”
- [ ] 我知道这是月付价、年付折算价还是活动价
- [ ] 我问清了**续费价**是否与首期价相同
- [ ] 我确认了流量是总量还是每月重置，以及有没有**倍率**
- [ ] 我估算了自己每月的真实用量，没有为用不上的大流量买单
- [ ] 同一家的价格在不同来源里差别很大时，我以官网结算页为准并截图

## 客户端与设备

- [ ] 我确认了服务商支持我要用的客户端（官方客户端 / 通用订阅导入 Clash 等）
- [ ] 我问清了**设备数限制**，以及超限时会怎样
- [ ] 我的客户端来自官方渠道，并保持更新

## 付款与退款

- [ ] 我读懂了**退款规则**：时间窗口、用量限制、套餐范围、退款去向
- [ ] 价格页面、退款规则、订单信息已**截图保存**（含日期和网址）
- [ ] 我选了有交易记录、可追溯的付款方式
- [ ] 页面默认选中的周期不是我想要的长周期，我已改成**月付**

## 红旗信号（出现越多越要小心）

- [ ] 价格在不同来源里说法不一致，无法预估真实成本
- [ ] 只强调“限时年付大折扣”
- [ ] 官方入口全程要求注册或验证码才能看到套餐
- [ ] 退款规则含糊，或没有退款说明
- [ ] 找不到任何稳定的客服渠道
- [ ] 出现“100% 稳定”“永久解锁”之类的绝对承诺
- [ ] 订阅链接是人工一次性发放、短时间失效
- [ ] 关联域名注册时间很短

## 兜底

- [ ] 我只买**最低档月付**，用满一个周期再决定
- [ ] 我有一个**备用方案**，不会因它出问题而完全断线
- [ ] 我不会把订阅链接发给任何人
