# 术语表（精简版）

用大白话解释看机场、VPN 介绍时最常遇到的词。每条都是「含义 → 对你的影响」。更完整的网页版见 <https://xtizi.com/cidian/>。

## 基础概念

- **机场**：中文网络里对一类代理订阅服务的俗称。服务商维护节点，你买套餐后拿到订阅链接，导入客户端使用。→ 它是服务形态，不是软件，必须配合客户端。
- **梯子**：“翻墙”的口语说法，泛指访问受限内容的各类工具。→ 不是具体产品，先分清 VPN、机场、自建等类型。
- **VPN**：虚拟专用网，在设备和远端服务器之间建立加密隧道。→ 通常装官方 App 即用，省心但灵活度较低。
- **节点**：机场里一台可供连接的服务器入口，通常按地区命名。→ 节点数量不等于好用，要看你用得到的地区和线路。
- **订阅链接**：服务商给你的一串网址，客户端靠它拉取最新节点列表。→ 等同账号凭证，不要外传。
- **客户端**：用来导入订阅、选节点并发起连接的软件。→ 购买前确认服务商是否支持你习惯的客户端。

## 线路与架构

- **线路**：从你到节点、再到目标网站所经过的整条路径。→ 同一地区的不同线路，延迟和稳定性可能差别很大。
- **IPLC / IEPL**：服务商用来描述“国际专线”的缩写。→ 这是服务商对架构的说法，用户很难直接验证，以自己实测的延迟和丢包为准。
- **中转**：先连入口服务器，再由它转发到出口服务器。→ 入口可能针对不同运营商优化，但多了一个环节。
- **落地节点**：最终真正访问目标网站的服务器，目标网站看到的是它的 IP。→ 流媒体等服务是否可用，与落地 IP 有关。
- **倍率**：节点扣流量的折算比例，倍率 2 表示用 1GB 扣 2GB。→ 套餐总流量要换算倍率，否则可能很快用完。

## 协议

- **协议**：客户端与节点之间传输数据所遵循的规则。→ 决定客户端能不能连上，多数人不需要自己选。
- **Shadowsocks（SS）**：较早出现、实现简单的轻量协议。→ 兼容性好。
- **VMess / VLESS**：V2Ray 系列协议，VLESS 更轻量，常搭配 TLS。→ 需要内核支持，旧客户端可能连不上。
- **Trojan**：把代理流量伪装成普通 HTTPS 流量。→ 依赖正确配置的证书与域名。
- **Hysteria2**：基于 QUIC 的较新协议，设计目标是在丢包较多的网络下保持可用。→ 需要较新的内核。
- **WireGuard / OpenVPN / IKEv2**：常见的 VPN 协议。→ 连不上时可以尝试换协议。

## 网络指标

- **延迟（Ping）**：数据往返一次所需的时间，单位毫秒。→ 稳定的中等延迟往往比忽高忽低的低延迟更舒服。
- **丢包率**：发出的数据包里没到达的比例。→ 对视频会议、游戏最敏感，比带宽更能反映“稳不稳”。
- **抖动**：延迟的波动程度。→ 抖动大时语音断续、游戏手感时紧时松。
- **带宽**：单位时间能传多少数据。→ 重要但不是稳定性的全部。
- **晚高峰**：通常指晚上 19:00–23:00 左右用户集中上网的时段。→ 评估稳定性必须包含它。

## 使用相关

- **规则模式 / 全局模式**：规则模式按规则分流，全局模式所有流量都走代理。→ 日常用规则模式，排查问题时临时切全局。
- **系统代理 / TUN 模式**：系统代理把代理设置写进系统；TUN 模式用虚拟网卡接管整机流量。→ 有的软件不走系统代理，这时要开 TUN。
- **订阅转换**：把一种格式的订阅转成另一种客户端能读的格式。→ 要把订阅链接交给第三方，有泄露风险。
- **流媒体解锁**：通过节点访问流媒体平台并正常观看对应地区内容的能力。→ 取决于节点 IP 是否被平台识别，是节点层面的差异。

## 购买与安全

- **设备数限制**：同一订阅允许同时在线的设备数量。→ 多设备使用前要问清。
- **年付折算价**：年付总价除以 12 得到的月均价。→ 看着低，但要一次性预付，不能和月付价直接比较。
- **跑路**：服务商突然停止服务或失联，已付费用难以追回。→ 小额月付、保留凭证、准备备用方案。
- **DNS 泄露**：域名解析请求没有走代理，本地网络仍能看到你访问了哪些域名。→ 影响隐私，也可能让分流失灵。
- **日志政策**：服务商关于是否记录你的连接信息的说法。→ “不记录日志”是自称，难以验证。
- **订阅更新**：客户端定期或手动重新拉取节点列表。→ 更新过于频繁可能被限制。
